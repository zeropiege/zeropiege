# zeropiege

Site web interactif avec vidéo contrôlée par le défilement

[![Netlify Status](https://api.netlify.com/api/v1/badges/zeropiege/zeropiege/deploy-status)](https://app.netlify.com/sites/zeropiege/deploys)

## Description

Ce projet est un site web moderne et interactif comportant une vidéo d'arrière-plan qui se joue en fonction du défilement de la page. Il comprend une navigation fixe, des sections pour présenter les fonctionnalités, un formulaire de contact et un pied de page.

## Fonctionnalités

- 🎥 **Vidéo héro interactive** : La vidéo d'arrière-plan se lit et se met en pause selon la position de défilement de l'utilisateur
- 📱 **Design responsive** : Adapté à tous les appareils (mobile, tablette, desktop)
- 📝 **Formulaire de contact** : Avec validation et feedback utilisateur
- 🎨 **Thème sombre moderne** : Avec des accents et transitions élégants
- 🔗 **Lien WhatsApp direct** : Pour faciliter le contact
- ⚡ **Performance optimisée** : Chargement efficace et animations fluides

## Structure du projet

- `index.html` - Structure HTML5 du site
- `style.css` - Styles CSS modernes et responsive
- `script.js` - Fonctionnalité JavaScript (vidéo contrôlée par défilement, formulaire)
- `video.mp4` - Vidéo d'arrière-plan pour la section héro

## Technologies utilisées

- HTML5
- CSS3 (avec Flexbox, Grid et variables)
- JavaScript Vanilla (ES6+)

## Installation

1. Clonez ce dépôt
2. Ouvrez `index.html` dans votre navigateur
3. Aucune dépendance supplémentaire requise

## Déploiement sur Netlify

Le site est configuré pour un déploiement automatique sur Netlify :

1. Connectez votre dépôt GitHub à Netlify
2. Le fichier `netlify.toml` configure automatiquement le build
4. Le déploiement se fait automatiquement à chaque push sur la branche `main`

## Personnalisation

Pour personnaliser ce site :
- Remplacez les textes entre crochets `[ ]` dans le HTML
- Substituez `video.mp4` par votre propre vidéo
- Modifiez les couleurs dans `style.css` pour matcher votre charte graphique
- Mettez à jour les informations de contact dans le HTML et le JavaScript

## Aperçu des sections

1. **Navigation fixe** - Toujours accessible en haut de page
2. **Section héro** - Avec vidéo contrôlée par le défilement
3. **Fonctionnalités** - Présentation en grille responsive
4. **À propos** - Description de l'entreprise/service
5. **Contact** - Formulaire et informations de contact
6. **Footer** - Informations de copyright
