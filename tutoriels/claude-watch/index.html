Apprenez à installer et utiliser Claude Watch pour analyser n'importe quelle vidéo (YouTube, TikTok, fichiers locaux) et en extraire le transcript, les scènes clés, le hook et la structure.

1. Installe Claude Watch

Colle simplement ce prompt dans Claude Code :

Installe Claude Watch pour moi depuis le repo officiel https://github.com/taoufik123-collab/claude-watch. Exécute toi-même dans le terminal `claude plugin marketplace add taoufik123-collab/claude-watch`, puis `claude plugin install watch@claude-watch --scope user --yes`. Vérifie que le plugin est bien installé et dis-moi clairement si je dois relancer Claude Code avant d'utiliser la commande /watch. Ne me redonne pas seulement les commandes : exécute-les.
Astuce : Cette commande installe officiellement le plugin Claude Watch depuis le répertoire officiel. Une fois installé, il sera disponible dans tous vos projets Claude Code.

2. Fais-lui regarder une vidéo

Remplace simplement le texte entre crochets. YouTube, TikTok, Instagram, Vimeo et les fichiers locaux sont pris en charge. Pour une vidéo sans sous-titres, Claude Watch peut proposer Whisper pour transcrire l'audio.

/watch [COLLE LE LIEN OU LE CHEMIN DU FICHIER] Résume cette vidéo, puis détaille son hook, sa structure, les éléments visuels, le son et les moments clés.
Exemple concret :
/watch https://www.youtube.com/watch?v=dQw4w9WgXcQ Résume cette vidéo, puis détaille son hook, sa structure, les éléments visuels, le son et les moments clés.
Note importante : Pour une vidéo sans sous-titres, Claude Watch peut proposer d'utiliser Whisper pour transcrire l'audio. Acceptez cette option si proposée pour obtenir un transcript complet.
